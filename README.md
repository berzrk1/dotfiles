# dotfiles

## Post-Installation

### fish plugins (fisher)

Plugins are listed in `~/.config/fish/fish_plugins`. Install fisher, then let it install the list:

| Machine | Command                                  |
| ------- | ---------------------------------------- |
| CachyOS | `sudo pacman -S fisher && fisher update` |
| macOS   | `brew install fisher && fisher update`   |
| Kali    | manual installation                      |
